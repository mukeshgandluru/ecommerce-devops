# E-Commerce DevOps Project

A microservices-based e-commerce application built to demonstrate
AWS DevOps, CI/CD, Infrastructure as Code, containerization,
Kubernetes and monitoring.

## Microservices

- User Service
- Product Service
- Order Service

## Current Technology

- Python
- Flask
- Git
- GitHub

## Services

| Service | Port |
|---|---:|
| User Service | 5001 |
| Product Service | 5002 |
| Order Service | 5003 |

## DevOps Technologies

- AWS

- Kubernetes / EKS
- Prometheus
